# Public repository scope

This repository is public. Publish software, installation guides, user workflows,
technical plans and verified research methodology here.

Keep internal business plans, pricing decisions, sale plans, valuations and buyer
discussions outside this repository. Do not include them in commits, release
notes, source archives, public app content or deployment bundles. Preserve any
requested internal notes in a private location outside this checkout.

Keep credentials, account records and licensed market data private. Before
publishing, review both tracked source and generated artifacts for private
material. Trading exit rules and provider usage costs are technical documentation
and remain part of the public toolkit.
